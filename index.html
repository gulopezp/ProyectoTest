R01 · Modelo y encapsulación

Fabricar una ficha de mensaje

Un mensaje tiene autor, texto y plazo en años. Nuestra primera clase es el molde para crear muchas fichas diferentes.

Pasos

  1. Crea el paquete model dentro del paquete base.
  2. Crea la clase Java MensajeFuturo.
  3. Escribe atributos private, constructor y getters.
  4. Crea una prueba de consola independiente.
model/MensajeFuturo.java 
package cl.duoc.dsy1102.timecapsule.model;

public class MensajeFuturo {
    private String autor;
    private String texto;
    private int plazoAnios;

    public MensajeFuturo(String autor, String texto, int plazoAnios) {
        this.autor = autor;
        this.texto = texto;
        this.plazoAnios = plazoAnios;
    }

    public String getAutor() { return autor; }
    public String getTexto() { return texto; }
    public int getPlazoAnios() { return plazoAnios; }
}
PruebaMensaje.java 
package cl.duoc.dsy1102.timecapsule;

import cl.duoc.dsy1102.timecapsule.model.MensajeFuturo;

public class PruebaMensaje {
    public static void main(String[] args) {
        MensajeFuturo m = new MensajeFuturo(
            "Carlos", "Hola, futuro yo", 5
        );
        System.out.println(m.getAutor());
        System.out.println(m.getTexto());
        System.out.println(m.getPlazoAnios());
    }
}
Debes ver: Carlos, Hola, futuro yo y 5 en la consola. Ahora sabes que una clase es un molde y new MensajeFuturo(...) crea un objeto.

Ver las fichas en pantalla

Ya sabemos fabricar mensajes, pero todavía viven en la consola. Necesitamos una ventana que los muestre: modelo → lista observable → tabla.

HelloController.java · ejemplo completo R02 
package cl.duoc.dsy1102.timecapsule;

import cl.duoc.dsy1102.timecapsule.model.MensajeFuturo;
import javafx.beans.property.ReadOnlyStringWrapper;
import javafx.collections.FXCollections;
import javafx.collections.ObservableList;
import javafx.fxml.FXML;
import javafx.scene.control.TableColumn;
import javafx.scene.control.TableView;

public class HelloController {
    @FXML private TableView<MensajeFuturo> tablaMensajes;
    @FXML private TableColumn<MensajeFuturo, String> colAutor;
    @FXML private TableColumn<MensajeFuturo, String> colTexto;
    @FXML private TableColumn<MensajeFuturo, String> colPlazo;

    @FXML
    private void initialize() {
        colAutor.setCellValueFactory(d ->
            new ReadOnlyStringWrapper(d.getValue().getAutor()));
        colTexto.setCellValueFactory(d ->
            new ReadOnlyStringWrapper(d.getValue().getTexto()));
        colPlazo.setCellValueFactory(d ->
            new ReadOnlyStringWrapper(
                d.getValue().getPlazoAnios() + " años"));

        ObservableList<MensajeFuturo> mensajes =
            FXCollections.observableArrayList();
        mensajes.add(new MensajeFuturo("Valentina", "Cumple tus sueños", 5));
        mensajes.add(new MensajeFuturo("Carlos", "Sigue estudiando", 10));
        tablaMensajes.setItems(mensajes);
    }
}
Comprobación: aparecen dos filas y tres columnas. Ojo: en R04 moveremos esta lista fuera del controlador, para compartirla entre pantallas.
R03 · Eventos y validaciones

Dejar que el usuario escriba

Antes nosotros escribíamos los mensajes en el código. Ahora añadiremos TextField para autor/texto, ComboBox para el plazo y un botón con onAction="#agregarMensaje".

Pasos

  1. En el mismo FXML añade campos y botón, con sus fx:id.
  2. Declara esos controles como @FXML en el Controller.
  3. En initialize() llena el ComboBox con 1, 5 y 10.
  4. Crea el método que valida, construye un MensajeFuturo y lo agrega a la lista.
Dentro de HelloController.java · método del botón 
@FXML private TextField campoAutor;
@FXML private TextField campoTexto;
@FXML private ComboBox<Integer> campoPlazo;

@FXML
private void agregarMensaje() {
    String autor = campoAutor.getText().trim();
    String texto = campoTexto.getText().trim();
    Integer plazo = campoPlazo.getValue();

    if (autor.isEmpty() || texto.isEmpty() || plazo == null) {
        System.out.println("Completa autor, mensaje y plazo");
        return;
    }

    MensajeFuturo nuevo = new MensajeFuturo(autor, texto, plazo);
    mensajes.add(nuevo);
}
Importante: es un fragmento, no un archivo completo. Debes añadir los imports, conservar mensajes como campo del Controller en esta etapa y configurar el ComboBox. El formulario no guarda todavía en disco.
Comprobación: un mensaje válido aparece en la tabla; campos vacíos no crean mensajes.
R04 · Dos vistas

Una pantalla para mirar y otra para escribir

Imagina dos habitaciones que comparten un mismo archivador. Si cada habitación fabrica su propio archivador, parecerá que los mensajes se pierden. Por eso ambas deben compartir la misma lista.

Listado

TableView y botón «Escribir nuevo mensaje».

Formulario

Autor, mensaje, plazo, Guardar y Cancelar.

Pasos

  1. Deja la tabla en hello-view.fxml.
  2. Crea formulario-view.fxml y FormularioController.java.
  3. En HelloApplication conserva la ObservableList y compártela con ambos controladores.
  4. Usa FXMLLoader para abrir la segunda pantalla.
  5. Al guardar, añade el mensaje a la lista compartida y vuelve al listado.
HelloApplication.java · fragmento de navegación

    getClass().getResource("formulario-view.fxml")
);
Parent root = loader.load();
FormularioController controller = loader.getController();
controller.configurar(this);
stage.setScene(new Scene(root, 860, 480));

R05 · Responsabilidades y JSON

Guardar los mensajes para mañana

La memoria es como una pizarra: se borra al apagar. Un archivo JSON es como un cuaderno: permite volver a leer lo escrito.

Pasos

  1. Crea los paquetes service y dao.
  2. Crea la interfaz MensajeDao, que define leer y guardar.
  3. Crea JsonMensajeDao, que implementa la interfaz usando Jackson.
  4. Crea MensajeService, encargado de validaciones y coordinación.
  5. Agrega la dependencia Jackson al pom.xml y revisa los requisitos del módulo.
  6. Adapta MensajeFuturo para deserializar (constructor vacío y setters según el ejemplo docente).
  7. Conecta el Controller al Service y guarda dos mensajes.
dao/MensajeDao.java 
package cl.duoc.dsy1102.timecapsule.dao;

import cl.duoc.dsy1102.timecapsule.model.MensajeFuturo;
import java.io.IOException;
import java.util.List;

public interface MensajeDao {
    List<MensajeFuturo> listar() throws IOException;
    void guardar(List<MensajeFuturo> mensajes) throws IOException;
}

R06 · Recuperación y pruebas

Que los mensajes estén seguros

Guardar no es suficiente si después no podemos recuperar los datos. Esta etapa verifica qué pasa al cerrar, reiniciar o encontrar un archivo dañado.

Cuatro comprobaciones obligatorias

  1. Reinicio: guarda dos mensajes, cierra la aplicación completamente y vuelve a ejecutar Launcher. Deben reaparecer ambos.
  2. Escritura más segura: el DAO escribe primero un temporal, conserva el anterior en .bak y después reemplaza el archivo.
  3. JSON defectuoso: comprueba que el programa detecta contenido inválido y no lo sustituye silenciosamente por una lista vacía.
  4. Pruebas: ejecuta el conjunto de pruebas del proyecto (JUnit y Maven).
Terminal · ejecutar pruebas 
mvn test

En Windows, si el repositorio incluye el Maven Wrapper, puedes utilizar mvnw.cmd test.

Comprobación: el mensaje sigue allí después de reiniciar; existe un respaldo cuando corresponde; el archivo defectuoso produce un error comprensible y las pruebas se ejecutan correctamente.

Primero: ¿qué es una carpeta y qué es un paquete?

Una carpeta es como un cajón en tu computador. Un archivo es una hoja dentro de ese cajón. En Java, un paquete es un conjunto de carpetas que IntelliJ puede crear por ti. Si escribes cl.duoc.dsy1102.timecapsule, IntelliJ crea las carpetas cl/duoc/dsy1102/timecapsule.

Abre IntelliJ IDEA → New Project → JavaFX → Maven → JDK 21. Nombre: time-capsule; grupo cl.duoc.dsy1102. También puedes abrir directamente la carpeta proyecto-java que entregamos, y ya tendrás todo creado.

Dos rutas importantes: src/main/java contiene clases Java. src/main/resources contiene las pantallas FXML. src/test/java contiene pruebas. ¡No las mezcles!

2. El orden más fácil para crear los archivos

  1. Crea o abre el proyecto en IntelliJ y comprueba JDK 21.
  2. Pega primero pom.xml y usa Reload Maven. Esto descarga las bibliotecas que necesitamos.
  3. Crea module-info.java y después las clases Java del paquete base.
  4. Crea los subpaquetes model, service y dao y completa cada clase.
  5. Crea las dos pantallas .fxml dentro de resources, en la ruta correcta.
  6. Crea las tres clases de pruebas en src/test/java.
  7. Ejecuta Launcher.main() o mvn clean javafx:run. Registra un mensaje y revisa data/mensajes.json.
  8. Cierra y vuelve a abrir la app. Ejecuta mvn test y revisa los resultados.
¿Por qué no existe la carpeta data?

package cl.duoc.dsy1102.timecapsule.service;

import cl.duoc.dsy1102.timecapsule.dao.MensajeDao;
import cl.duoc.dsy1102.timecapsule.model.MensajeFuturo;
import java.io.IOException;
import java.util.ArrayList;
import java.util.List;

public class MensajeService {
    private final MensajeDao dao;
    private final List<MensajeFuturo> mensajes;

    public MensajeService(MensajeDao dao) throws IOException {
        this.dao = dao;
        this.mensajes = new ArrayList<>(dao.listar());
    }

    public MensajeFuturo registrar(String autor, String texto, Integer plazoAnios)
            throws IOException {
        if (autor == null || autor.isBlank()) {
            throw new IllegalArgumentException("Debes indicar el autor.");
        }
        if (texto == null || texto.isBlank()) {
            throw new IllegalArgumentException("Debes escribir un mensaje.");
        }
        if (plazoAnios == null || plazoAnios <= 0) {
            throw new IllegalArgumentException("Selecciona un plazo válido.");
        }

        MensajeFuturo nuevo = new MensajeFuturo(
                autor.trim(), texto.trim(), plazoAnios
        );
        List<MensajeFuturo> actualizados = new ArrayList<>(mensajes);
        actualizados.add(nuevo);
        dao.guardar(actualizados);
        mensajes.add(nuevo);
        return nuevo;
    }

    public List<MensajeFuturo> listar() {
        return List.copyOf(mensajes);
    }
}

package cl.duoc.dsy1102.timecapsule.dao;

import cl.duoc.dsy1102.timecapsule.model.MensajeFuturo;
import com.fasterxml.jackson.core.JsonProcessingException;
import com.fasterxml.jackson.core.StreamReadFeature;
import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.json.JsonMapper;

import java.io.IOException;
import java.nio.file.AtomicMoveNotSupportedException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;
import java.util.Arrays;
import java.util.List;

public class JsonMensajeDao implements MensajeDao {
    private static final TypeReference<List<MensajeFuturo>> TIPO_MENSAJES =
            new TypeReference<>() {};

    private final Path archivo;
    private final ObjectMapper mapper = JsonMapper.builder()
            .enable(StreamReadFeature.STRICT_DUPLICATE_DETECTION)
            .build();
    private byte[] versionConocida;
    private boolean versionRegistrada;

    public JsonMensajeDao(Path archivo) {
        this.archivo = archivo;
    }

    @Override
    public List<MensajeFuturo> listar() throws IOException {
        System.out.println("[R06][DAO] Archivo leído: "
                + archivo.toAbsolutePath().normalize());
        byte[] contenido = leerContenidoActual();
        if (contenido == null) {
            System.out.println("[R06][DAO] Archivo ausente; primera ejecución sin datos.");
            versionConocida = null;
            versionRegistrada = true;
            return List.of();
        }
        List<MensajeFuturo> recuperados = leerYValidar(contenido);
        System.out.println("[R06][DAO] JSON válido; mensajes recuperados: "
                + recuperados.size());
        versionConocida = contenido;
        versionRegistrada = true;
        return recuperados;
    }

    private byte[] leerContenidoActual() throws IOException {
        if (Files.notExists(archivo)) return null;
        return Files.readAllBytes(archivo);
    }

    private List<MensajeFuturo> leerYValidar(byte[] contenido) throws IOException {
        try {
            List<MensajeFuturo> recuperados = mapper.readValue(contenido, TIPO_MENSAJES);
            if (recuperados == null || recuperados.stream().anyMatch(this::esInvalido)) {
                throw preservarArchivoDanado(new IOException("Estructura JSON inválida."));
            }
            return recuperados;
        } catch (JsonProcessingException error) {
            System.err.println("[R06][DAO] Jackson rechazó el archivo: "
                    + archivo.toAbsolutePath().normalize());
            throw preservarArchivoDanado(error);
        }
    }

    private boolean esInvalido(MensajeFuturo mensaje) {
        return mensaje == null
                || mensaje.getAutor() == null || mensaje.getAutor().isBlank()
                || mensaje.getTexto() == null || mensaje.getTexto().isBlank()
                || mensaje.getPlazoAnios() <= 0;
    }

    private IOException preservarArchivoDanado(IOException causa) {
        Path copia = null;
        try {
            Path directorio = archivo.toAbsolutePath().getParent();
            copia = Files.createTempFile(
                    directorio, archivo.getFileName() + ".corrupt-", ".json");
            Files.copy(archivo, copia, StandardCopyOption.REPLACE_EXISTING);
            return new IOException(
                    "El JSON está dañado. Se conservó una copia en "
                            + copia.toAbsolutePath()
                            + ". Revisa el respaldo .bak antes de continuar. "
                            + "El archivo original no se modificó.", causa);
        } catch (IOException errorCopia) {
            if (copia != null) {
                try { Files.deleteIfExists(copia); }
                catch (IOException errorLimpieza) { errorCopia.addSuppressed(errorLimpieza); }
            }
            IOException error = new IOException(
                    "El JSON está dañado y no fue posible crear una copia de resguardo. "
                            + "No se modificó el archivo original.", causa);
            error.addSuppressed(errorCopia);
            return error;
        }
    }

    @Override
    public void guardar(List<MensajeFuturo> mensajes) throws IOException {
        Path destino = archivo.toAbsolutePath();
        Path directorio = destino.getParent();
        Files.createDirectories(directorio);

        byte[] contenidoActual = leerContenidoActual();
        if (contenidoActual != null) leerYValidar(contenidoActual);

        if (versionRegistrada && !Arrays.equals(versionConocida, contenidoActual)) {
            throw new IOException("El archivo JSON cambió mientras la aplicación estaba "
                    + "abierta. No se guardó el mensaje para evitar perder datos. "
                    + "Cierra y vuelve a abrir la cápsula.");
        }
        if (!versionRegistrada) {
            versionConocida = contenidoActual;
            versionRegistrada = true;
        }

        Path temporal = Files.createTempFile(directorio, "mensajes-", ".tmp");
        try {
            mapper.writerWithDefaultPrettyPrinter().writeValue(temporal.toFile(), mensajes);
            byte[] nuevaVersion = Files.readAllBytes(temporal);
            if (!Arrays.equals(versionConocida, leerContenidoActual())) {
                throw new IOException("El archivo JSON fue modificado mientras se "
                        + "preparaba el guardado. Operación cancelada.");
            }
            if (contenidoActual != null) {
                Path respaldo = destino.resolveSibling(destino.getFileName() + ".bak");
                Files.copy(destino, respaldo, StandardCopyOption.REPLACE_EXISTING);
            }
            try {
                Files.move(temporal, destino,
                        StandardCopyOption.ATOMIC_MOVE,
                        StandardCopyOption.REPLACE_EXISTING);
            } catch (AtomicMoveNotSupportedException error) {
                Files.move(temporal, destino, StandardCopyOption.REPLACE_EXISTING);
            }
            versionConocida = nuevaVersion;
        } finally {
            Files.deleteIfExists(temporal);
        }
    }
}
